**PackForge 1.2.0** — mods are suggested as you build, and updates come to you.

### Suggestions while you build a pack

- Installing any project now offers a handful of projects that go with it, filtered to that instance's Minecraft version and loader and ranked by Modrinth's own relevance for the name you just installed. Each suggestion shows its download count and whether its listing references the project you installed.
- One click adds it to the instance. The panel slides in when an install finishes, animates each suggestion into place, and gets out of the way when you dismiss it.
- For anything Modrinth does not host, the panel links straight to a CurseForge search for the same name. CurseForge browsing inside the app is not built yet — that needs their API and a content provider that is not limited to Modrinth's API, which is a larger piece of work.

### Install animations

- Content rows shimmer while a download runs and flash green the moment it finishes, so an install is visible even if you are looking at something else.

### PackForge updates itself

- Releases are now signed and ship an update manifest. The app checks **this repository's** newest release — never Modrinth's update endpoint — verifies the signature, and can download and install the new version in place. Windows applies it quietly; macOS and Linux apply it when you restart.
- If you are on 1.1.0 or older, install this build once by hand. From 1.2.0 onwards the app updates itself.

### Installing these builds

- The installers are still **unsigned**, so Windows SmartScreen warns on first run ("More info" → "Run anyway") and macOS Gatekeeper blocks the first launch (right-click → Open, or `xattr -dr com.apple.quarantine`).
- `PackForge_1.2.0_*.exe.sig`, the macOS/Linux `.tar.gz` archives and their `.sig` files, and `latest.json` are the update artifacts the app consumes. The ordinary installers are still attached for fresh installs.
